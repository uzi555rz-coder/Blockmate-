# BlockMate Privacy Policy

**Effective date: November 9, 2026**

BlockMate is a local companion app for Minecraft Bedrock survival worlds. It helps users analyze JSON building blueprints and follow a manual, layer-by-layer build guide.

## Information BlockMate accesses

When you choose a JSON building blueprint, BlockMate reads that user-selected file on the device to calculate dimensions, block quantities, material stacks, and a manual build order. The file is not uploaded by BlockMate as part of this local analysis.

BlockMate does not request or use Android Accessibility access, screen capture, overlay permission, camera, microphone, location, contacts, SMS, or notification access. It does not control Minecraft, read Minecraft screen content, or place blocks.

BlockMate does not request or collect a Microsoft account password. It does not sell personal information and does not use Minecraft content for advertising or profiling.

## Storage and sharing

Local preferences such as onboarding completion, guide progress, calibration state, and selected limits may be stored on the device. BlockMate does not sell or share this information with data brokers. Blueprint files are processed locally.

## Your choices

You can use the app without granting sensitive Android permissions. You can remove local app data by uninstalling BlockMate or clearing its storage.

## Children

BlockMate is not designed to collect personal information from children. It does not require an account.

## Changes and contact

We may update this policy when the app’s data practices change. The latest policy should be published at the stable HTTPS URL shown in any future store listing.
