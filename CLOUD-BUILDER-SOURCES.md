# Cloud builder sources

- Expo local app development: https://docs.expo.dev/guides/local-app-development/
  - Expo documents local Android compilation with `pnpm expo run:android`; this requires Android Studio/SDK and is not a phone-only path.
- Expo development builds: https://docs.expo.dev/develop/development-builds/introduction/
  - A custom development build is required for native libraries that Expo Go does not contain. Expo documents local compilation and EAS cloud compilation as separate options.
- GitHub Actions billing: https://docs.github.com/en/billing/managing-billing-for-your-products/managing-billing-for-github-actions/about-billing-for-github-actions
  - Standard GitHub-hosted runners are free for public repositories. Private repositories use the account's included Actions allowance.
- Codemagic pricing: https://codemagic.io/pricing/
  - Codemagic lists a free individual plan with 500 build minutes per month and one parallel build.
- Bitrise pricing: https://bitrise.io/pricing
  - Bitrise lists a free Hobby plan with build credits for a small project and one team member.
